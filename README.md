# 通勤ルート運行情報ダッシュボード

以下のルートの公式運行情報ページへすぐアクセスできる静的サイトです。

- JR中央線快速: 国分寺 → 東京
- 湘南新宿ライン / りんかい線: 新宿 → 東京テレポート
- 京王バス

## 使い方

`index.html` をブラウザで開く（またはリポジトリを任意の静的ホスティングに配置する）だけで利用できます。ビルド手順や依存パッケージはありません。

各カードのボタンから運行会社の公式サイト（JR東日本 / りんかい線を運行する東京臨海高速鉄道 / 京王バス）を新しいタブで開きます。遅延情報そのものを自動取得・表示するものではなく、公式情報への導線をまとめたリンク集です。
